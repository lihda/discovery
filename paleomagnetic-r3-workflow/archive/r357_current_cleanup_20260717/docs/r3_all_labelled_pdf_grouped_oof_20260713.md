# R3 全部有标签且有 PDF 目标的分组 OOF 评测

日期：2026-07-13

> 后续更新：本文记录原始 `mean4` 基线。2026-07-15 的 R2E/GREP 论文内成对排序
> 嵌套 OOF 已将全覆盖正确率提高到 83.61%；见
> `docs/r3_r2e_pairwise_ranking_20260715.md`。下文数字保留用于基线复现。

## 结论

当前冻结的 R3 `mean4` 全文方法在全部可解析 PDF 目标上的五折 REFNO
分组 OOF 正确率为 **82.48%（2,269/2,751）**，未达到 90% 目标。
95% Wilson 区间为 81.01%--83.85%。

四个组成模型中 HGB 的事后观察正确率最高，为 82.59%；它只比预先冻结的
`mean4` 高 0.11 个百分点，不能解释为已经获得了稳定的新提升。

| 范围 | 目标数 | 文献数 |
|---|---:|---:|
| 当前具有 R3 标签 | 3,173 | 1,627 |
| 有本地 PDF | 2,751 | 1,478 |
| 有 PDF 但无法解析 | 0 | 0 |
| 实际纳入 OOF | 2,751 | 1,478 |
| 无本地 PDF，跳过且不计入分母 | 422 | 149 |

主页面缓存有 21 篇 PDF 的正文为空。固定缓存融合规则优先采用主缓存，只有主
缓存为空时才使用声明顺序中的第一个非空备用缓存。这 21 篇均由第一备用
MinerU 缓存恢复。因此，本次没有因解析失败额外排除目标。

## 评测方法

- 使用五个确定性的 REFNO 分组折；同一 REFNO 的所有目标始终位于同一测试折。
- 每个目标恰好获得一次 OOF 预测，训练该预测的模型完全排除了该目标所属文献。
- 输入特征来自已有 R3 知识库、criterion/taxonomy 和原始 PDF 正文。
- 不使用 PMAGRESULT、当前行 ROCKMAG、历史 OOF 或已有评测结果作为运行时特征。
- REFNO 仅用于文献级隔离，RESULTNO 仅用于预测与标签对齐。
- 主方法在读取本轮标签前冻结为四个 combined 专家的概率等权均值，阈值为 0.5。

这里的“训练”仍会使用其余四折的 R3 标签来拟合模型；因此该结果是文献隔离
的内部 OOF 泛化评测，不等同于一次完全外部、从未参与方法开发的独立验证。

## 阈值实验

`mean4` 在 0.5 阈值下有 300 个 FP 和 182 个 FN，因此提高阈值能够减少误报。
直接在全部 2,751 个 OOF 标签上事后搜索时，经验最优阈值为 0.562832，正确率
为 83.28%（2,291/2,751；TN/FP/FN/TP = 804/240/220/1,487）。这比 0.5
高 0.80 个百分点，但搜索过程已经读取全部答案，只能视为乐观上限，不能作为
新的正式泛化结果。

为避免用外层测试答案选阈值，又进行了五外层折、每个外层训练集内五折 REFNO
分组 OOF 的嵌套实验：

| 阈值规则 | Accuracy | Balanced accuracy | TN / FP / FN / TP |
|---|---:|---:|---:|
| 固定 0.5 | 82.48% | 80.30% | 744 / 300 / 182 / 1,525 |
| 内层 0.01 网格选择 | 81.90% | 81.21% | 818 / 226 / 272 / 1,435 |
| 内层精确经验最优 | 81.86% | 81.35% | 827 / 217 / 282 / 1,425 |

嵌套网格在五个外层折选出的阈值为 0.57、0.49、0.68、0.64、0.59，波动较大。
提高阈值确实改善了类别平衡并减少 FP，但新增 FN 更多，最终准确率反而下降。
因此当前不应把默认阈值从 0.5 改为 0.56；阈值调整无法把当前方法提升到 90%。
完整阈值结果位于
`tmp/r3_all_labelled_pdf_grouped_oof_v1/nested_threshold_report.json`。

## 解释

当前主要误差不是 PDF 缺失或解析空白造成的：所有有 PDF 的文献均已得到非空
正文。错误更偏向负类，300 个 FP 明显多于 182 个 FN；正类召回率已经达到
89.34%，但负类召回率只有 71.26%。这说明现有全文特征能够发现大部分 R3
阳性证据，却仍难以把“论文提到了岩石磁学方法”与“该 RESULTNO 对应对象拥有
足够的 R3 载磁矿物证据”可靠区分。目标对象与正文中的样品、组分或表格行之间
缺少稳定链接，仍是达到 90% 的主要信息瓶颈。

## 目标数量定位实验

“单目标文献”定义为同一 REFNO 在完整 3,173 行 R3 身份清单中只对应一个
RESULTNO。直接复用已冻结的 OOF 预测，不重新训练或选择阈值，结果如下：

| 文献分组 | 目标数 | 文献数 | Accuracy | Balanced accuracy |
|---|---:|---:|---:|---:|
| 单目标 | 872 | 872 | 87.96% | 86.84% |
| 多目标 | 1,879 | 606 | 79.94% | 77.67% |
| 恰好 2 个目标 | 652 | 326 | 84.66% | 82.75% |
| 3--4 个目标 | 693 | 207 | 84.27% | 81.88% |
| 至少 5 个目标 | 534 | 73 | 68.54% | 67.30% |

多目标文献继续按标签结构拆分后：

| 文献分组 | 目标数 | 文献数 | Accuracy |
|---|---:|---:|---:|
| 同一文献全部目标标签一致 | 1,601 | 545 | 85.45% |
| 同一文献内同时存在 R3=0 和 R3=1 | 278 | 61 | 48.20% |

在 61 篇混合标签文献中，58 篇（95.08%）的所有目标被当前流程判成同一个值，
没有一篇文献的全部目标均判断正确。这直接表明当前特征主要表达“整篇论文是否
存在 R3 相关证据”，尚未表达“证据属于哪个 RESULTNO 对象”。单目标子集的
0.5 阈值正确率已经接近 90%，但事后最优阈值也只有 88.53%，因此修改 criterion
语义仍可能改善剩余误差；多目标混合标签组则必须优先解决目标级证据归属。

完整机器可读结果位于
`tmp/r3_all_labelled_pdf_grouped_oof_v1/target_multiplicity_report.json`。

## 单目标 criterion 修改实验

在 872 篇单目标文献中，历史 `ROCKMAG` 非空与 R3 标签的一致率为 96.33%
（TN/FP/FN/TP = 274/21/11/566）。据此将历史实践语义从“方法 + 载体识别 +
剩磁意义解释”三项全部满足，修改为以下任一替代路径：

1. 原文中实施或报告了合格的岩石磁学/矿相表征方法；
2. 原文给出能够自证测量已实施的诊断结果；
3. 原文把载磁矿物明确归因到剩磁或磁化分量。

仍排除参考文献/引文、未实施或未来方法、普通退磁温度区间、裸 `SUSC`、裸
`AN` 以及未与方法、诊断或剩磁建立关系的裸矿物名。新增的 378 维实践语义
特征包含正文/参考文献命中差异、方法事件的实施/结果语气、定量诊断、方法与
载体/诊断共现以及载体归因。

全覆盖实验没有突破 90%：

| 分支 | 单目标 Accuracy |
|---|---:|
| 原冻结 `mean4` | 87.96% |
| 只用单目标训练 | 86.70% |
| ROCKMAG 非空监督 | 88.30% |
| 排除 ROCKMAG 冲突文献训练 | 88.19% |
| 实践语义特征与原模型融合 | 88.76% |
| 标题/ROCKNAME 与原模型融合 | 88.76% |
| 乐观元路由筛查 | 88.07% |

因此新版校准实践 criterion 使用明确的选择性输出，而不是把中间概率强制二值化：

| 输出 | 固定条件 |
|---|---|
| `DOES_NOT_MEET_PRACTICE_PROXY` | `p <= 0.30` |
| `MEETS_PRACTICE_PROXY` | `p >= 0.70` |
| `ABSTAIN` | `0.30 < p < 0.70` |

在单目标 grouped OOF 上，该策略判定 722/872 行，覆盖率 82.80%，已判定正确率
92.66%，混淆矩阵为 TN/FP/FN/TP = 197/32/21/472。五折已判定正确率分别为
92.91%、90.26%、91.10%、95.77%、93.53%；原 holdout 单目标分区为 90.07%
（141/177 行被判定）。阈值是在单目标开发分析中选择的，不是全新外部验证；
正确率必须与覆盖率一起报告。

新版产物为 `data/calibration/r3_rockmag_practice_criterion_v2.json`，其依赖校验器
为 `scripts/r3_calibrated_practice_criterion.py`，完整结果位于
`tmp/r3_all_labelled_pdf_grouped_oof_v1/single_target_selective_policy_report.json`。
