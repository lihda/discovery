## 1. 文档定位与严格口径

本文讨论的核心方案可暂定名为：

**一种基于冻结判据规范、目标及磁化分量绑定、可撤销规则关系和可追溯原文证据的古地磁文献知识冲突检测方法、系统、设备及存储介质。**

“严格知识模式”须同时满足以下条件：

1. 在线评分不读取 `PMAGRESULT`、`ROCKUNIT` 或其他源数据库业务字段；
2. 在线评分不读取 R3、R5、R7 已有标签、已有评测结果或历史预测文件；
3. 在线评分只允许读取身份清单、原始文献文本、已冻结的专家知识库和已冻结的规范判据；
4. 离线知识归纳与在线评分物理分离，预测文件固定并计算哈希后，才允许独立评测进程读取标签；
5. 证据不足或目标归属不明确时拒判；支持与冲突并存时保留 `evidence_status=BOTH`，即使冻结判据按优先级给出 0，也不得删除支持关系或伪装成原文中不存在矛盾。

R3 已在固定 `exact300` 开发基准上取得 300 行全覆盖、按 `REFNO` 分组的 OOF accuracy `270/300 = 90.00%`。该结果不是新的不可回看外部验证，也不代表 2,172 行 PDF-only 全量、R5 或 R7 已达到 90%。专利主张仍应围绕可重复的技术结构、数据边界、证据推理和审计机制展开，并精确披露实验范围，不能用单一开发基准替代外部技术效果验证。

## 2. 技术问题

古地磁质量指标通常需要从论文正文、图表说明和讨论段落中恢复证据。仅靠数据库字段或全篇关键词命中存在以下技术问题。

### 2.1 近答案字段造成信息泄漏

`PMAGRESULT.ROCKMAG` 等字段与 R3 判断具有很强关联。如果在线评分直接读取该字段，或者按当前批次 `R3=1` 的记录筛选词项，就会把接近答案的信息带入评分过程。该方式即使在同一数据集上得到较高准确率，也不能证明系统能够脱离表格从原文作出判断。

### 2.2 文献中的证据对象容易错配

同一篇论文可能讨论多个岩体、地层、样品组或磁化分量。全篇出现 “magnetite”“post-folding” 或 “remagnetization”，不等于这些表述属于待评估目标。参考文献、背景综述和其他目标的描述也会产生大量伪命中。

### 2.3 否定、模态和时序改变语义

下列文本不能通过单一关键词作同义处理：

- “magnetite was identified” 与 “no magnetite was identified”；
- “positive fold test” 与 “fold test was negative/failed”；
- “rotation occurred” 与 “rotation cannot be excluded” 或 “no evidence of rotation”；
- “post-folding secondary component” 与 “post-kinematic intrusion carrying primary TRM”；
- “younger pole is similar” 与论文仅在背景中提到一个 younger pole。

系统需要同时处理极性、模态、事件先后关系、磁化分量和目标对象归属。

### 2.4 多条证据可能相互矛盾

论文可能同时包含风险证据和补救证据。例如，某段认为一个分量是后期叠加，另一段又以野外检验支持另一分量的原生性。普通加权平均或多数投票会把这种矛盾抵消掉，导致系统输出一个表面上高置信、实际上不可审查的二元结论。

### 2.5 评分过程缺少可验证边界

仅在说明文字中声称“不使用标签”不足以排除意外读取。需要在输入模式、文件读取权限、知识库结构、输出字段和事后评测顺序上形成可机器检查的闭环。

## 3. 总体技术方案

本方案采用“两阶段、四类在线输入、证据态与判决态分层、独立事后评测”的架构。

```text
阶段 A：离线知识归纳
历史术语字段（仅 ROCKMAG 内容列） + 领域知识
        -> 去标识化、规范化、概念归并
        -> 术语节点及共现边
        -> 专家审查规则、排除式和语义门控
        -> 冻结知识库版本 + SHA-256

阶段 B：在线无标签评分
身份清单 + 原文页缓存 + 冻结知识库 + 冻结规范判据
        -> 输入边界校验
        -> 目标锚定和候选片段检索
        -> 否定/模态/时序/分量门控
        -> SUPPORT / CONFLICT / UNKNOWN 关系
        -> 规则适用/被击败/未决状态
        -> 保留矛盾质量的证据聚合
        -> SUPPORTED_ONLY / REFUTED_ONLY / BOTH / NEITHER 证据态
        -> 1 / 0 / ABSTAIN 判决态
        -> R3/R5/R7 输出、证据链和运行哈希

独立评测（只能在预测落盘并固定哈希之后执行）
冻结预测 + 隔离标签
        -> 按 RESULTNO 对齐
        -> accuracy、coverage、known accuracy、macro-F1、F1(0) 等
```

其中，在线评分只允许以下四类数据输入：

| 输入 | 最小内容 | 作用 | 明确禁止的内容 |
| --- | --- | --- | --- |
| 身份清单 | `REFNO`、`RESULTNO`、`ROCKNAME` | 定位论文、输出记录和待评估目标 | R1-R7、ROCKMAG、结构字段、历史预测 |
| 原文页缓存 | `REFNO`、页号、正文、章节提示、来源质量标志 | 提供可引用的原始证据 | 评测标签、源数据库结果字段 |
| 冻结专家知识库 | 规则、术语、排除式、阈值、版本和来源声明 | 将原文证据映射为知识关系 | `REFNO/RESULTNO` 答案映射、标签监督参数 |
| 冻结规范判据 | R3/R5/R7 来源命题、三值逻辑表达式、来源位置和原始附件哈希 | 约束哪些证据组合能够形成正式判决 | 行级答案、经验标签、评测反馈参数 |

## 4. 阶段 A：离线、去标识化的 R3 术语知识归纳

### 4.1 合规的数据使用方式

离线归纳程序可以只读取 `PMAGRESULT.ROCKMAG` 的内容列，用于统计历史上出现过的岩石磁学术语，但必须满足：

1. 不读取 `REFNO`、`RESULTNO` 或其他记录标识；
2. 不读取 R3、R5、R7 标签或评测结果；
3. 不按 `R3=1`、`R3=0` 或任何评价结果筛选字段值；
4. 不在知识产物中保留原始整段字段值；
5. 只保留规范化概念、文档频次、概念共现边和必要的检索表达式；
6. 归纳完成后由专家审查、版本化并冻结，在线评分只读冻结后的聚合知识产物。

用户最初设想的“把 PMAGRESULT 中被评为 1 的字段值作为专家知识”会使用评价标签进行筛选，因此不符合本文的严格实施例。若未来保留这种变体，应明确标为“标签监督实验变体”，与严格无标签方案、严格测试集和专利效果数据隔离。本文建议的严格替代方案是：不按评分筛选 ROCKMAG 值，而由领域语义规则独立判断某个概念能否代表载磁矿物诊断方法。

### 4.2 术语图结构

术语归纳结果不是行级答案表，而是记录无关的概念图：

- **方法节点**：IRM/SIRM、三轴 IRM、Lowrie、热磁曲线、磁化率-温度曲线、`Js-T/Jrs-T`、磁滞、FORC、矫顽力、光学显微镜、SEM/TEM/EDS、EPMA、XRD 等；
- **载体节点**：magnetite、titanomagnetite、hematite/haematite、maghemite、pyrrhotite、greigite、goethite、ilmenite 等；
- **诊断节点**：饱和行为、Curie 温度、磁畴状态、Koenigsberger ratio 等；
- **共现边**：两个概念在同一去标识化 ROCKMAG 值中共同出现的次数和归一化频次。

现有 `r3_rockmag_lexicon_v1` 产物记录了 4,775 个非空源值，其中 4,704 个至少匹配一个已知概念，术语归纳覆盖率为 98.513089%；包含 24 个达到频次阈值的概念和 192 条共现边。该数字只说明**术语本体对离线字段表达的覆盖程度**，不代表 R3 预测准确率，也不能作为 90% 目标已经实现的证据。方法、载体、诊断三类频次可以重叠，不能相加解释为样本总数。

### 4.3 从术语图到冻结专家规则

专家知识库中的每条规则至少包含：

- 唯一规则编号；
- 所属指标 R3、R5 或 R7；
- 中英文可读命题；
- 语义谓词和证据组；
- `SUPPORT`、`CONFLICT` 或复核型 `UNKNOWN/null` 效果；
- 正向检索式、排除式和可选的候选片段子类型；
- 最低目标绑定阈值；
- 基础置信度和冲突类型；
- `label_supervision=false` 的来源声明。

知识库加载时应拒绝包含 `REFNO`、`RESULTNO`、`answer`、`gold`、`benchmark label` 等记录级答案含义的键或文本，并拒绝 `label_supervision` 不为 `false` 的知识产物。

### 4.4 历史监督的 ROCKMAG-to-text 蒸馏实施例

为验证用户提出的“从历史 ROCKMAG 表达归纳专家知识，再回到原文重建相同语义”的路线，另设 `rockmag_text_distilled_v1` 实验配置。该配置不是 4.1 节的严格无监督实施例，必须明确披露其离线阶段使用了历史 `R3` 标签和 `PMAGRESULT.ROCKMAG`。两者只允许在固定训练分区中联结；在线评分仍不得读取源表、标签、既有评测或既有预测。

论文级固定划分采用：

`SHA256("r3-rockmag-distillation-v1" + NUL + REFNO)[0:8] / 2^64 < 0.20`

由此得到训练分区 2,473 行、1,292 个 REFNO，封存留出分区 700 行、335 个 REFNO。离线产物 `r3_rockmag_text_distillation_v1.json` 只保存聚合方法、诊断、载体模式、训练统计和排除规则，不保存原始 ROCKMAG 文本、原文引文、记录标识或逐行答案；本轮运行固定的文件 SHA-256 为 `149df539a937678c8204aa6d6e60e77bd901e4a77975d26caa5362749aa18ad4`。

字段语义先被归一化为以下代理门：

1. 合格方法加诊断结果，例如目标绑定的 IRM acquisition 加“不饱和至 1 T”；
2. 合格方法加载体识别，例如 `Js-T` 曲线识别 hematite 并伴少量 magnetite；
3. 显微方法加载体或蚀变观察；
4. `Tub=150-450C` 等仅表示分量解阻区间的描述、裸 `SUSC`、裸 `AN` 和裸矿物名均不能单独触发。

在线输出保持双轨。`normative_r3` 仍执行上传判据的“方法 + 载体识别 + 剩磁意义解释”三组门控，缺链返回 `ABSTAIN`；`rockmag_proxy_r3` 判断原文能否重建一个可报告的 ROCKMAG 式证据事件。当代理为 1 而正式链不完整时，输出 `criterion_practice_conflict=true` 和 `INCOMPLETE_NORMATIVE_CHAIN`，并强制人工复核。这样并未静默篡改正式 criterion，而是把历史实践与规范要求之间的差异转化为可检测的知识冲突。

为更直接检验“只把训练正例 ROCKMAG 归类为专家知识”的设想，本轮另生成 `r3_positive_rockmag_expert_kb_v2.json`。它同样是监督变体，明确声明 `label_supervision=true`，只允许读取固定训练分区；留出分区的标签和 ROCKMAG 单元格均不打开。训练正例共 1,523 行，其中 1,496 行 ROCKMAG 非空；1,489 行可归入已知概念，占非空正例 99.53%；1,458 行含方法事件，1,341 行形成“方法 + 诊断或载体”强链。冻结产物只保留 27 个语义概念、66 条原文检索模式、149 条正例概念共现边及聚合频率，不保留 `REFNO/RESULTNO/ROCKNAME`、逐行 ROCKMAG、原文引文或答案映射。其 SHA-256 为 `b0fc28866fe6702938a7cc02fcf7b87b68abc9e3b4e391a53a53de1615b5e9ef`；重复生成逐字节一致。

实践阈值被单独固化为 `r3_rockmag_practice_criterion_v1.json`，而没有覆盖规范 v2。该实践判据把“可归属于目标、已实施且可报告的岩磁或矿相表征事件”作为正路径，不再强制要求正式链中的显式载体识别和剩磁意义解释；但仍排除单独的 `Tub`、裸 `SUSC`、裸 `AN`、裸矿物名、参考文献语境和未实施方法。无原始 PDF 返回 `SKIP_NO_SOURCE`；论文级传播仅允许单目标论文或原文明示的共享样品作用域。系统由此可以同时输出规范 R3、实践 R3 及二者的知识冲突，而不是用一个降级判据静默替换科学规范。

后续单目标定位实验进一步形成监督校准的
`r3_rockmag_practice_criterion_v2.json`。它把历史兼容正路径明确改为三选一：

该结果属于开发 grouped OOF，阈值已经参与开发，尚非外部独立验证；专利材料

该实施例的可专利技术重点不应表述为“把表格答案搬到原文”，而应表述为：训练分区监督的去标识化语义蒸馏、在线数据面隔离、目标绑定的证据事件重建、正式判据与实践代理的双轨比较，以及预测先哈希后评测的完整性控制。

## 5. 阶段 B：在线无标签评分

### 5.1 输入边界校验

评分启动前执行以下校验：

1. 身份清单只能有一个工作表，列名和顺序严格为 `REFNO/RESULTNO/ROCKNAME`；
2. 三个身份值均不得为空，`RESULTNO` 和完整身份元组必须唯一；
3. 原文页缓存中的 `REFNO` 集合必须与身份清单完全一致，不得多出或缺失论文；
4. 页缓存顶层、来源层和页面层只接受白名单字段；
5. 冻结知识库必须通过答案映射、标签监督和来源声明审计；
6. 评分子进程只允许读取上述四个显式输入，写入新建或空的输出目录；
7. 评分子进程禁止网络连接和再次创建子进程；
8. 评分前后分别计算四个输入文件哈希，发现输入变化则终止运行。

这些约束使“不参考 PMAGRESULT 表、不参考已有评测结果”从约定升级为可执行的访问控制和机器审计。

### 5.2 目标绑定

系统为每个 `ROCKNAME` 建立目标特征，包括规范化全名、特异词、通用词和名称特异度。候选证据按以下层级绑定到目标：

1. 目标全名与规则命中位于同一句；
2. 足够比例的目标特异词与规则命中位于同一句；
3. 多目标论文中，目标与命中位于同一有界段落或同一表格行，且该作用域不出现任何 sibling target；
4. 目标和命中位于同一页或相邻页；
5. 仅在单目标论文中使用弱的全文归属假设；
6. 多目标论文中没有局部目标锚点的命中降为低绑定关系。

现有引擎在同句全名命中时给出最高绑定值；特异词命中、独占段落/表格行、同页命中和单目标文档假设依次降权。每条 R3 命中保存稳定的 `scope_id`、`scope_kind`、目标是否独占以及检测到的竞争目标。只有评分身份清单提供了完整 sibling target 集合时才启用作用域升级；依赖该升级的 method 与 carrier/diagnostic/significance 还必须具有兼容 `scope_id`，从而避免把同页不同段落的证据拼接为一条链。多目标论文受到更强惩罚。每条规则还设有最低绑定阈值：普通 R3 支持规则为 0.48，R3 明确缺失规则为 0.78，R5 风险规则为 0.78，R5 补救规则为 0.70，R7 风险规则为 0.82，R7 补救规则为 0.72。未达到阈值的命中输出 `UNKNOWN/TARGET_SCOPE`，不能直接作为支持或冲突票。

当同一 `REFNO + canonical ROCKNAME` 对应多个 `RESULTNO`、而身份清单没有分量名称、方向或 pole 等可定位字段时，系统不得仅因目标名称相同而共享行级结论。它可以保留文章-目标层证据候选，但正式逐记录结果必须 `ABSTAIN/IDENTITY_AMBIGUOUS`，等待由原文生成的 component manifest 完成映射。

### 5.3 原文片段和来源质量

每个候选片段保留页号、章节、命中文本、上下文引文、字符起止位置和来源类型。参考文献区命中被标为来源噪声并降为 `UNKNOWN/PROVENANCE`。对于乱码/CID 字形、文本过短、疑似提取不完整或无可提取文本的页面，来源质量系数被降低；没有原文时输出 `UNKNOWN`，不以默认值冒充有证据结论。

证据置信度可表示为：

```text
evidence_confidence
  = base_rule_confidence
  * source_quality
  * (0.45 + 0.55 * target_binding)
  * lexical_or_subtype_match_quality
```

该值限制在预设区间内，用于证据质量融合，不等同于经过概率校准的真实正确概率。

### 5.4 无标签质量门控的多解析器回退

对于没有文本层、页数异常、正文过短、CID/乱码或疑似截断的 PDF，系统可以调用 MinerU 等版面感知解析器，但不能默认用新解析覆盖全部旧缓存。当前实施例先依据缓存质量标志和本地 PDF 可用性选择候选，再比较 base 与 MinerU 的有效页数、规范化字符数、风险标志、乱码量、领域关键词覆盖和 R3 核心概念集合。缺少可靠物理页边界的候选不生成可检索页；base 已有的 IRM、磁滞/热磁方法、显微方法、载体及载体-剩磁联系等关键概念也必须被候选保留。Base 为空时接受具有可靠页界的非空候选；base 非空时，只有强风险被消除、内容显著增加或多个质量维度共同改善且没有关键回退时才替换。每个替换或保留原因均进入 summary，选择和仲裁过程不读取标签、PMAGRESULT、旧评测或旧预测。

新增的页级融合模式不再要求整篇文献只能选择一个解析器。系统按物理页号对齐候选，但同一页仍只能选择一个完整来源，禁止把两个解析器的文字拼接后制造伪段落。候选页须通过字符保留、block confidence、低置信 block 比例和 R3 概念保真门，并至少在段落结构、表格行、乱码或内容量之一形成实质改善；每页选择、拒绝原因及指标写入独立审计数组。

训练分区实测中，21 篇零文本 PDF 全部恢复出非空原文；9 篇已有文本的强风险 PDF 中替换 8 篇，并因内容回退保留 1 篇。使用保守的行级身份歧义策略时，MinerU 将 coverage 从 68.5402% 提高到 70.0768%，accuracy 从 58.5524% 提高到 58.7141%，净增加 4 个正确结果；再加入独占段落/表格行作用域后 accuracy 为 58.9163%，净再增加 5 个正确结果。早期 64.3348% 数字依赖无法由三列运行时身份输入证明的同名 RESULTNO 共享，已经撤回。该结果证明条件式解析回退与结构化作用域均可用，但也证明解析器不是当时严格规则路径未达 90% 的主因。完整实验口径见 `docs/r3_mineru_training_experiment_20260711.md`；这些数字来自训练期 post-hoc 开发实验，不能当作新的独立留出集结果。

在已经打开过标签的 700 行固定留出分区上做非独立回归检查时，本次作用域改动没有改变任何一行的 `R3/OUTCOME/policy_decision`，accuracy 仍为 59.00%。因此当前证据只支持“训练期小幅改善且既有留出结果未退化”，不支持跨数据集精度提升主张。

该模块可形成一项独立的工程技术特征：**基于原解析质量状态触发候选解析器，使用与标签无关、保持页界和领域核心概念的多维文本质量函数作保守替换，并把路由、候选、仲裁和证据哈希纳入同一来源链**。它区别于无条件 OCR、简单字符数择优和依据最终分类正确与否选择解析器的做法。

## 6. R3 专门语义门控

R3 的正式正命题是：**待评估目标采用合格方法研究剩磁载体，识别载体或载体族，并解释该载体对被评估剩磁的意义。**

R3 不是简单搜索某个矿物名，而是将证据组织为三类关系：

| 证据组 | 典型证据 | 作用 |
| --- | --- | --- |
| method | IRM/SIRM、Lowrie、热磁曲线、磁滞/FORC、矫顽力、显微/微探针/XRD 等 | 证明实施了能够诊断载磁矿物的方法 |
| carrier | magnetite、hematite、pyrrhotite 等具体矿物或明确的 magnetic carrier | 提供必需的载体身份或载体族识别 |
| bridge/significance | “remanence is carried by magnetite”、载体对原生/次生解释的影响等 | 完成载体与被评估剩磁及其意义之间的语义闭环 |

strict v2.1 将 `method`、`carrier` 和 `bridge` 三组全部设为必需支持组。仅命中 IRM、磁滞或显微方法，只能证明开展了某种实验，不能独立形成 R3=1；仅出现矿物名也不能证明论文已经识别其为待评估剩磁的载体。任一必需组未解决时，正式判决为 `ABSTAIN/UNKNOWN`，不得把检索沉默解释为 R3=0。该组合门控与冻结规范中的 `ELIGIBLE_METHOD AND IDENTIFY AND SIGNIFICANCE` 一致。

同时设置高绑定的明确反证规则，例如“no remanence carrier was identified”。载体名处于明确缺失或否定从句时，不得被正向载体规则重复计票。相同规则在同一页、同一引文哈希上的重复命中去重；聚合时每条规则只保留最强证据，避免同一段被当成多条独立证据。

## 7. R5 专门语义门控

R5 的正命题是：**待评估方向具有充分的构造校正和古水平面控制。**

strict v2.1 不再把任意 tilt correction 或 positive fold test 直接等同于 R5=1。正式正向判决至少需要下列锚点之一：

```text
cratonic_rigidity
    = 目标区域自磁化获得以来一直是克拉通的刚性组成部分

OR

temporal_rescue
    = 目标结果来自最后一期变形事件之后侵位的侵入体
```

一般的 structural correction、未变形/小倾角描述和正野外检验属于辅助支持组，只能增强或解释上述结构基础，不能独立满足正式正向门槛。

### 7.1 冲突规则

- 目标属于 allochthonous 或 parautochthonous 地体；
- 目标来自 non-stratified/non-layered 岩石；
- 目标区域发生内部垂直轴旋转；
- 古水平面或产状信息明确缺失；
- 已变形目标没有进行所需构造校正，且同一声明中不存在“未变形、无明显构造扰动、倾角可忽略”等无需校正原因；
- 倾斜或旋转不能排除；
- 磁化获得之后发生垂直轴或块体旋转；
- 目标磁极或方向依赖倾角压扁校正，但缺少判据指定的独立佐证。

“post-folding secondary component”本身不直接等价于 R5=0。它可能是已被去除的低温叠加，而最终方向来自另一高温分量；也可能只是在描述无需恢复到褶皱前坐标的次生分量。缺少被评估分量、保留/去除状态和最终方向绑定时，该规则只输出复核型 `UNKNOWN/TEMPORAL_ORDER`。

### 7.2 可撤销例外与规则优先级

引擎实现了记录无关的 `unless_support_groups` 机制。例外只攻击声明该例外的具体冲突规则，并保留原始冲突关系、击败状态、例外关系编号、页号和引文哈希。它不是“出现一条好证据就抵消所有坏证据”的全局加权。

R5 当前存在两类严格限定的例外：

```text
post_final_deformation_intrusion
    -> 只解除规则中明确声明的 setting 类冲突
       （例如非层状/外来地体/内部旋转设置）
    -> 不解除 inclination-flattening 冲突

inclination_flattening_correction
    -> 默认 CONFLICT
    -> 只有下列任一同目标独立佐证可击败该冲突：
       1. 夹层火山岩具有相近 R-value；
       2. 同一层序的其他沉积岩无需压扁校正。
```

所有未被明确例外击败的正式冲突均优先于普通支持：底层 `evidence_status` 可以保留为 `BOTH`，但 `policy_decision` 为 0。只有先完成规则级 exception 解析，才进入正向支持组门控。该分层既保留矛盾，也避免普通 tilt correction、undeformed 或 field-test SUPPORT 把正式冲突稀释成 `UNKNOWN` 或 1。

否定和上下文排除也属于 R5 门控的一部分。例如，图注中的 “shown uncorrected for tilt” 可能只是说明绘图坐标，不必然说明最终方向未经构造校正；“no evidence of rotation” 应抑制 rotation 风险；“fold test failed/negative” 应抑制正向野外检验补救。

## 8. R7 专门语义门控

R7 的正命题是：**待评估磁化为原生磁化，而不是可证实的年轻磁极或后期叠加。**

R7 的正式判断必须比普通主题关键词具有更严格的目标、分量、时序、统计和地理约束。规范中的合格年轻参照至少应同时满足：

- 目标磁极和参照磁极均具有坐标及 A95；
- 参照磁极比目标年轻超过一个地质时期；
- 参照磁极可靠度为 `R>=3`；
- 参照来自相连克拉通内的稳定区域，而不是造山带；
- 两个 A95 包络在球面上发生重叠；
- 不存在将目标磁化约束为早于该年轻参照的野外证据。

仅在论文背景、参考文献或其他岩体段落出现 “younger pole”“remagnetization” 不能将当前目标判为 R7 冲突。strict v2.1 将普通 “matches a younger pole” 文本规则降为候选型 `UNKNOWN`；只有完整、目标绑定且满足上述必要字段的比较才能形成正式 R7 判决。明确把被评估分量解释为 younger remagnetization 或 secondary overprint 的证据仍可形成冲突，但必须通过同句目标、分量、否定和来源门控。

R7 的正式正向组 `formal_r7_decision` 目前只接受两种证据：

- 有记录的完整检索证明：相连稳定克拉通内所有 `R>=3` 合格年轻磁极均不与目标 A95 重叠；
- 目标绑定的野外证据将磁化年龄约束为早于其所相似的年轻磁极。

primary TRM、primary DRM、positive fold/contact/conglomerate/reversal test、与同期 APWP 一致或文本声称“不像年轻磁极”，都可作为辅助证据，但不能在缺少 `formal_r7_decision` 时独立给 R7=1。当前代码已经实现该支持组门槛和冲突优先级，但尚未拥有可进行全库数值比较的参考极目录，因此 formal R7 的实际覆盖率仍接近零。下一阶段不能继续依靠增加文本同义词，而应先建设带坐标、A95、年龄、时期、`R>=3`、克拉通范围和来源溯源的参考极数据产品。

## 9. 证据态、规则态与判决态分层

每条证据相对于指标正命题被映射为以下关系：

- `SUPPORT`：目标绑定证据支持正命题；
- `CONFLICT`：目标绑定证据与正命题冲突；
- `UNKNOWN`：来源缺失、目标绑定不足、参考文献噪声或证据质量不足；
- `MIXED`：在不设置冲突优先的指标中，独立支持规则和独立冲突规则同时成立。

关系记录还可以标记 `POLARITY`、`VALUE_RANGE`、`TEMPORAL_ORDER`、`TARGET_SCOPE`、`COMPONENT_SCOPE`、`MODALITY`、`PROVENANCE` 和 `EVIDENCE_DISAGREEMENT` 等冲突类型，使人工复核能够知道问题来自否定极性、时序、目标错配还是证据互斥。

strict v2.1 进一步把证据事实、规则适用性和最终判决分开：

| 层 | 取值 | 含义 |
| --- | --- | --- |
| `evidence_status` | `SUPPORTED_ONLY/REFUTED_ONLY/BOTH/NEITHER` | 原文中是否存在活动支持、活动冲突、二者并存或二者均未建立 |
| 规则态 | `ACTIVE/DEFEATED/UNDECIDED` | 规则是否适用、是否被其声明的 exception 击败、或因目标/来源不足而未决 |
| `policy_decision` | `1/0/ABSTAIN` | 在必需支持组、可撤销例外和冲突优先级处理后的正式判决 |

例如，R5 同时出现普通 structural SUPPORT 和未被击败的 allochthonous CONFLICT 时，`evidence_status=BOTH`，但因正式冲突优先，`policy_decision=0`。该设计保留了原始矛盾，不把政策判决伪装成“原文中只有反证”。

知识关系与二元兼容值应严格区分。现有输出为兼容旧表格，在 `UNKNOWN/MIXED/ABSTAIN` 时可以携带二元占位值：R3 使用 0，R5/R7 使用 1，同时保留正式 coverage 和人工复核状态。该占位值不能被解释为知识引擎已经给出确定的负例或正例。专利方案的核心输出应主张证据态、规则态、判决态及可审计关系，二元兼容列只属于可配置的下游接口。

## 10. 保留矛盾质量的证据聚合

系统使用受 Dempster-Shafer 证据思想启发的未归一化合取聚合，但不在聚合过程中丢弃矛盾质量。

设累计质量为支持 `S`、冲突 `C`、未知 `U` 和矛盾 `K`，初值为：

```text
S0 = 0, C0 = 0, U0 = 1, K0 = 0
```

第 `i` 条独立规则证据的质量为 `(a, b, u)`：支持证据取 `a=q, b=0`，冲突证据取 `a=0, b=q`，且 `u=1-q`。递推为：

```text
S' = S*a + S*u + U*a
C' = C*b + C*u + U*b
U' = U*u
K' = K + S*b + C*a
```

输出时对 `S/C/U/K` 的总和进行尺度归一化，但保留独立的 `contradiction=K` 通道。与直接把冲突质量归一化掉的方法相比，该机制能够显示支持证据和反证同时存在的程度。

为避免伪独立性，聚合前先按“规则编号 + 关系 + 页号 + 引文哈希”去重，再对每条规则只选置信度最高的 `SUPPORT/CONFLICT` 记录。证据层始终保留支持与冲突共存的 `BOTH` 状态；判决层可依据冻结判据执行冲突优先或规则级 exception，但不能删除原始关系。

该实现只能准确表述为“受 Dempster-Shafer 与 transferable belief model 启发的冲突保留质量聚合”。当前规则权重未经概率校准，来源之间的独立性也只做了规则级近似，因此不能泛化声称已经实现标准 Dempster 归一化、完整 TBM 或概率化真值发现。专利主线应放在目标绑定、可撤销关系、依赖去重和证据溯源的具体技术链上。

## 11. 可审计证据链和哈希

每个输出关系至少保存：

- 规则编号、指标、证据组、关系和冲突类型；
- 中英文专家命题、语义谓词和时序三元组；
- 引文、命中文本、页号、章节和字符位置；
- 目标绑定方法和绑定分数；
- 提取方法和来源质量；
- `quote_sha256` 与 `page_text_sha256`；
- 知识库版本与 `kb_sha256`；
- 运行时来源清单和聚合方式。

严格工作流还计算身份清单、原文缓存、知识库、规范判据和三个预测文件的 SHA-256，并在运行清单中记录。规范判据同时声明其所形式化的原始附件哈希。哈希的作用是证明“评测时使用的是哪一版输入、规范、知识和预测”，支持复现及篡改检测；哈希本身不证明文献陈述真实，也不替代专家审查。

## 12. 独立事后评测

评分命令不接受标签参数，也不执行准确率计算。合规评测顺序如下：

1. 在不挂载标签文件的评分进程中完成 R3/R5/R7 预测；
2. 计算并固定预测文件、知识库、规范判据和运行清单哈希；
3. 关闭评分进程；
4. 启动独立评测进程，读取冻结预测和隔离的标签文件；
5. 仅通过 `RESULTNO` 对齐结果；
6. 输出评测报告，不将误差样本、标签或调参结果反馈到同一次评分运行。

若根据评测结果修改规则，必须生成新的知识库版本和哈希，并在新的 REFNO 留出集或外部集上重新验证。不能在测试集上逐条修正规则后继续把该测试集称为独立验证集。

1. 建设版本化参考极目录，至少包含参照磁极标识、纬度、经度、A95、年龄区间、地质时期、可靠度 `R`、稳定/造山属性、现代及古地理克拉通范围、连通关系、来源 DOI/页表位置、提取方式和哈希；

5. 在 DOI、引用关系、页面和 claim 层建立来源依赖图，避免同源摘录或引用复制被当成多条独立证据；
6. 使用冻结外部集验证规则覆盖和错误率；只有取得独立、可交换的有标签校准集后，才考虑 conformal 或 risk-coverage 校准。

### 14.4 可供权利要求组织的具体技术链

以下组合可作为权利要求和说明书的候选技术特征，但是否具有新颖性、创造性及其保护范围仍须由专利代理人结合检索结果判断。不得把 DS、四值逻辑、argumentation 或 conformal 等通用理论本身表述为本项目独创。

1. **两阶段数据隔离**：离线从近答案术语字段归纳去标识化概念图，在线只使用冻结聚合知识，不再访问源字段、标签或历史结果；
2. **记录无关的 ROCKMAG 术语图**：仅保存规范概念、频次和共现关系，删除原始字段值及行标识，以图中的方法-载体-诊断关系指导原文重点片段检索；
3. **目标绑定的知识冲突检测**：把目标全名、特异词、页级位置、多目标状态和规则阈值共同用于判断证据是否属于待评估对象；
4. **指标专门语义门控**：R3 使用方法/载体/桥接结构，R5 使用构造控制与变形-磁化时序结构，R7 使用目标磁极、磁化分量、年轻参照和原生性结构；
5. **否定、模态及时序联合判断**：通过正向规则、排除式和事件关系，区分未识别、不能排除、检验失败、后褶皱次生分量与构造后原生侵入体；
6. **证据态与判决态分层**：在同一目标证据图中保留 `SUPPORTED_ONLY/REFUTED_ONLY/BOTH/NEITHER`，再根据必需支持组、专属 exception 和冲突优先级输出 `1/0/ABSTAIN`；
7. **矛盾质量保留聚合**：合取聚合时保留支持与冲突交叉产生的矛盾质量，不将其归一化丢弃，并据此触发 `MIXED` 或人工复核；
8. **规则级独立性控制**：先以规则、页号和引文哈希去重，再按规则选取最强证据，抑制同一句或同一规则重复命中造成的置信度膨胀；
9. **可执行的评分访问边界**：对允许输入、敏感文件读取、输出目录、网络和子进程实施 fail-closed 控制，并对输出执行禁止字段审计；
10. **证据与运行双层哈希溯源**：同时记录引文/页面哈希、知识库哈希和输入输出文件哈希，使结论能够定位到特定规则、特定原文和特定运行版本；
11. **预测与评测的单向隔离**：预测落盘并固定哈希后才允许独立评测，避免标签或评测结果反馈到同一次推理过程。

建议的权利要求布局包括：

- 独立方法权利要求：覆盖离线归纳、冻结规范校验、在线目标/分量绑定、可撤销关系、证据态/判决态分层和可追溯输出的组合流程；
- 独立系统权利要求：覆盖知识构建模块、边界校验模块、原文检索模块、语义门控模块、证据聚合模块和审计模块；
- 设备及存储介质权利要求：覆盖执行上述步骤的处理器和程序；
- 从属权利要求：分别限定 R3、R5、R7 的门控结构、目标绑定分级、规则级去重、哈希审计和独立评测顺序。

不建议把某个具体正则表达式、当前阈值数值或某一术语列表写成唯一实现方式。说明书可将其作为实施例，权利要求宜概括为“语义模式及其排除条件”“最低目标绑定条件”和“事件关系约束”，以避免保护范围被当前词表锁死。

最后一项 OOF 融合明显优于规则 scorer，但权重是在训练分区 OOF 概率上选择的，尚未经过新的外部文献集验证，不能作为正式 78.12% 泛化精度，更不能据此外推 90%。该候选保持在隔离实验脚本中，没有写入 `knowledge_strict` 的正式判决路径。

该融合在 5 个外折上的 accuracy 为 79.60%、79.60%、76.36%、78.34% 和 76.72%；按 `REFNO` 整组重采样 5,000 次得到的开发期 bootstrap 95% 区间约为 74.51%--81.55%。该区间仍受 OOF 后选权重影响，只用于说明当前结果与 90% 存在明显距离，不是正式泛化置信区间。

为了形成可部署的专家分流候选，另对同一 OOF 概率实施非对称选择性判决：`p<=0.40` 自动判 0、`p>=0.80` 自动判 1，其余进入人工复核。开发聚合结果为 coverage 51.23%、known accuracy 90.21%、macro-F1 89.22%、`F1(0)=85.94%`、`F1(1)=92.49%`，混淆为 379/89/35/764。该阈值同样是在训练 OOF 上 post-hoc 选择的，而且 5 折 known accuracy 为 91.98%、83.39%、89.06%、94.03% 和 93.93%，并非每折均达到 90%。因此它只能作为“约一半样本自动分流、其余专家复核”的待验证实施例，不能表述为全量或稳定 90%。

未达 90% 的主要原因已经可以量化：

1. **历史标签与规范 criterion 不同义。** 训练分区只以 `ROCKMAG` 是否非空预测 R3 就达到 96.04%，而上传 criterion 要求“合理识别载磁矿物并评论其对剩磁的意义”。当前标签更接近数据库是否登记过 ROCKMAG 信息；原文规则识别到真实岩磁证据时，仍可能与历史登记状态冲突。
2. **原文缺失直接消耗误差预算。** 训练分区 1,292 篇论文中有 114 篇、288 行没有可用原文，其中 154 行标签为 1。若无来源时继续强制兼容值为 0，仅该项就把理论全量上限压到 93.77%；要达到 90%，其余 2,185 个有来源行必须达到约 95.73%，远高于当前能力。
3. **主要召回损失发生在目标归属，不是术语识别。** 有原文且没有 cross-target 拒绝的 1,046 行当前 accuracy 为 83.37%；出现至少一个 `cross_target_or_unbound` 的 1,139 行只有 48.64%。在 1,496 个 `R3=1 且 ROCKMAG 非空` 的训练行中，除 151 行无来源和 324 行不在当前 taxonomy 表达范围外，928 行能在全文恢复至少一个对应概念，另有 93 行全文没有恢复字段概念。概念通常存在，但未必能安全绑定到目标。
4. **标签大多是论文级属性，但原文信号不足以完全重建。** 1,292 篇中 1,237 篇的行标签完全同质，若预先知道每篇论文的多数标签，行级 oracle 为 95.79%。但整篇 TF-IDF 只有 70.89%，论文级知识特征模型约 77%，说明数据库登记状态不能仅由正文词频稳定推断。
5. **版面解析是次要问题。** 对 3 篇完全按无标签质量选出的真实双栏 PDF，页级融合采用 15 页 MinerU、保留 9 页 base，并因 R3 概念丢失拒绝 2 个候选页；段落边界由 0 恢复为 90，表格行由 0 恢复为 114。它新增 1 条完整规范链，但二元代理 0 行变化，accuracy 仍为 63.08%。此前 8 篇留出 MinerU 补充同样只提高 coverage，没有提高 accuracy。
6. **分类器容量不是唯一瓶颈。** 从线性文本、字符 n-gram、知识计数 Logistic 到浅层梯度提升和论文多数层融合，分组 OOF 只从约 73% 提升到 78.12%，FP 和 FN 仍分别为 299 和 242。继续增加无来源或无目标绑定的模型复杂度，缺乏达到 90% 的实验证据。

本轮新增的可实施技术特征包括：同一物理页的多解析器单源仲裁、页级 R3 概念保真和 block-confidence 门控、结果限定词到材料别名的保守恢复、论文级与目标级知识特征双层推理，以及把规范判决、实践代理和训练期兼容模型隔离输出。这些结构可以写入专利实施例；准确率效果仍须用新的外部 `REFNO` 文献集验证。

### 15.1.2 R3 PDF-only、正例知识与目标传播实验（2026-07-12）

本轮按用户要求把“无本地 PDF”固定为预测后评测前的来源筛选条件。筛选只读取页缓存中的 `source.pdf_path` 和 `no_local_pdf` 质量标志，并在打开标签前写入哈希回执。训练分区 1,292 篇、2,473 行中，1,174 篇、2,172 行具有本地 PDF；其余 118 篇、301 行全部跳过，不进入下列任何准确率分母。PDF-only 标签分布为 804 个 0 和 1,368 个 1。

首先将严格目标标题后的检索窗口从普通正文的 2 句/650 字符扩展为最多 8 句/2,400 字符，并在新标题、sibling target、参考文献或表格边界处立即截断。冻结预测后评测显示，目标小节作用域把规则 accuracy 从 65.10% 提高到 65.56%，新增 14 个 TP 和 4 个 FP，净增加 10 个正确目标；混淆矩阵由 667/137/621/747 变为 663/141/607/761。该结果支持“标题下连续方法段”是有效的局部归属信号，但其增益不足以解释剩余差距。

随后比较确定性传播和 `REFNO` 分组 OOF 策略：

同配置消融说明，正例 ROCKMAG KB 对目标局部 HistGradient 的净增益为 1.38 个百分点，FP 减少 24、TP 增加 6；但各自选择最佳共享传播策略后，含 KB 版本反而比 taxonomy-only 低 0.18 个百分点。知识库更适合改善目标局部区分，不能据此扩大论文级传播范围。其另一项明显效果出现在选择性分流：在同一开发 OOF 上，以 `p<=0.325` 自动判 0、`p>=0.90` 自动判 1，可在 48.94% coverage 上得到 90.31% known accuracy、`F1(0)=89.28%`、`F1(1)=91.16%`；不加载正例 KB 时，在约 90.30% known accuracy 下 coverage 为 40.84%。这些阈值是在开发 OOF 上 post-hoc 选择，不能解释为独立风险保证或全覆盖 90%。

传播实验在打开标签前先以身份清单、PDF 页缓存和冻结 taxonomy 生成 2,172 行候选，候选 SHA-256 为 `8ff1a752c079474b22ce48bea88e9d48fe8825c6f381bb353ff10db2216984d7`；候选冻结后才读取训练标签和既有冻结预测。重新计算的直接实践代理与冻结目标小节预测逐行 0 mismatch。显式共享样品 pair 传播使用 `all/both/each samples` 等原文量词、方法执行语境和所有目标锚点，净增加 261 个 TP，同时增加 90 个 FP。要求共享范围内已经存在一个严格目标阳性的保守版本仅达到 66.71%。因此，传播可以修复大量漏报，但“论文标签大多同质”不能直接替代原文作用域证明。

本轮瓶颈可以进一步量化：

1. **多目标归属主导规则漏报。** 单目标 963 行 accuracy 为 84.63%，多目标 1,209 行只有 50.37%；607 个 FN 中 573 个来自多目标，548 个至少包含一次 `cross_target_or_unbound` 拒绝。目标标题扩窗和新增词法都无法替代共享样品、材料别名、表格行或磁化分量的明确关系。
2. **术语覆盖已经接近饱和。** 正例 ROCKMAG 非空值的已知概念覆盖为 99.53%。正例 KB 可使目标局部非线性模型提高 1.38 个百分点，却没有提高最佳共享传播的全覆盖结果。继续罗列同义词的边际收益有限，下一步应增加“方法事件作用于哪个样品/目标/分量”的关系抽取。
3. **历史标签主要是论文级登记属性，但存在混合论文。** 1,174 篇 PDF 中 1,126 篇标签完全同质；若预先知道论文多数标签，行级 oracle 为 96.82%。然而带正例 KB 的 OOF 在同质论文行上为 86.73%，在 48 篇混合标签论文的 220 行上只有 47.27%。oracle 使用真实标签，只说明理论结构，不是可部署结果。
4. **canonical target 等价并非当前缺失开关。** 1,903 个 `REFNO + canonical ROCKNAME` 组的标签多数 oracle 为 99.72%，181 个重复目标组中仅 6 组、13 行标签混合；但当前实践代理已经按 canonical target 缓存和共享二值，额外解除重复 `RESULTNO` 歧义没有改变任何预测。后续增益必须来自原文组件定位，而不是再次共享同一结果。
5. **校准跨折漂移。** 在该 2,172 行 PDF-only 路径中，外折内选出的全覆盖阈值在 0.375--0.65 间变化，嵌套阈值结果反而低于固定阈值模型；该路径未形成稳定的 90% 全覆盖阈值，也不能以全 OOF 后选阈值替代外部验证。
6. **部分 FP 可能是专家知识与历史登记的真实冲突。** IRM、热磁、磁滞、Curie 温度、磁铁矿/赤铁矿等原文证据在部分历史 0 行中仍完整出现。对这些行应输出“原文实践代理支持、历史评价不一致”的冲突状态并交由专家复核，不能为了贴合标签而删除科学上有效的证据。

因此，截至 2026-07-12 的本轮 2,172 行 PDF-only 实验不支持“R3 已达到 90% 全覆盖准确率”的结论。当前较诚实的实用部署方式是双层输出：在外部文献集重新冻结并校准后，对高置信样本自动分流，对其余样本输出目标绑定证据包、冲突类型和人工复核任务。可写入专利实施例的新增结构包括：标签监督但记录无关的正例术语/共现图、PDF 可用性先冻结后评测、目标小节有界扩窗、canonical target/论文/共享样品三级作用域、传播资格与反例阻断、规范判据和实践判据双轨冲突、以及覆盖率受约束的专家复核分流。

### 15.1.3 R3 exact300 nested router 与论文一致性校准（2026-07-13）

在固定 `exact300` 身份清单上，后续实验将原文科学证据表示与历史字段赋值策略分层：六个异构专家从原文/PDF、冻结专家知识、own-study、目标归属和 source-derived component bridge 产生概率；historical-policy router 仅在每个外折训练区的 `REFNO` 隔离 OOF 上学习专家选择。外折测试论文在所有辅助训练行中完整排除，运行时不读取 `PMAGRESULT`、逐行 `ROCKMAG`、旧 OOF 或旧评测。

冻结 nested router 基线为 268/300=89.33%。论文一致性 v2 对同一论文的多行结果进行受控校准：折 1/3/4/5 中所有候选平滑器的二元判决完全相同，因而在不查看外折标签时保留 identity；折 2 的候选判决不同，才以外折训练区的完整二级 `REFNO` cross-fit OOF 选择 `paper_min_blend_100`。该训练 OOF 上候选 accuracy 为 83.62%，identity 为 82.38%；最终只修正 2 个 FP，未引入新错误。

规范结果为 270/300=90.00%，五折 accuracy `91.67/95.00/81.67/90.00/91.67%`，macro-F1 89.06%，balanced accuracy 88.47%，TN/FP/FN/TP `91/19/11/179`。规范运行时固定为 Python 3.9.6、NumPy 2.0.2、scikit-learn 1.6.1。正式报告 `tmp/r3_exact_300_resultno_v2/paper_consistency_v2/report.json` 的 SHA-256 为 `c77788373ddc3c227504f9f544f2df0c3348ceb201d6764da4178613d72b2cd9`，复现说明见 `docs/r3_exact300_paper_consistency_90pct_20260713.md`。

这一结果支持专利实施例采用“科学证据头 + 历史策略头 + 冲突输出 + 论文级一致性校准”：科学证据头回答原文是否满足严格 criterion，历史策略头预测数据库历史赋值习惯，两者不一致时保留为知识冲突；论文级校准只改变 historical-policy 输出，不覆写原文事实关系。它只证明固定 `exact300` 开发基准达到 90.00%，尚未证明 2,172 行全量或新论文外部泛化率达到 90%。

### 15.2 严格评测协议

正式实验应采用按 `REFNO` 分组的留出集或外部文献集，保证同一论文的多个 `RESULTNO` 不会跨训练/验证边界。知识库、规范判据、阈值和术语图须在查看测试标签前冻结并计算哈希。

建议至少报告：

- 全部样本 accuracy；
- 原文可用率和正式 `policy_decision` 非 `ABSTAIN` coverage；
- known accuracy，即只在正式 `policy_decision` 为 0 或 1 的样本上的准确率；
- macro-F1、每类 precision/recall/F1，特别是 R5/R7 的 `F1(0)`；
- 混淆矩阵、`ABSTAIN`、`BOTH/NEITHER` 比例和人工复核率；
- 按单目标/多目标、原文质量、文献年代和指标类别分层的结果；
- 置信区间，而不仅是单点百分比。

“尽可能达到 90% 以上”应明确是哪一个指标：全部样本 accuracy、known accuracy 还是某类覆盖率。若通过大量 `ABSTAIN` 获得较高 known accuracy，必须同时报告 coverage，不能只展示被系统接受的样本。

### 15.3 支撑技术效果的消融实验

为了证明技术特征带来的实际效果，建议在同一 REFNO 留出集上比较：

1. 全文关键词基线；
2. 仅术语图检索、无目标绑定；
3. 加入目标绑定；
4. 再加入否定和参考文献排除；
5. 再加入 R5/R7 时序与分量门控；
6. 普通多数投票或丢弃冲突质量的聚合；
7. 本文的矛盾质量保留聚合；
8. 去掉文件访问边界后的功能等价版本，用于说明边界主要提升可验证性而非预测精度。

每个消融版本均应在预测落盘后由同一独立评测器计算指标。这样可以把“目标绑定降低跨对象误报”“时序门控改善 R5/R7 的 0 类识别”“矛盾保留提高风险样本复核质量”等技术效果与具体结构对应起来。

## 16. 实用性与部署方式

该方案可以部署为本地批处理服务、受控服务器任务或文献审核辅助系统。实际使用流程为：导入论文和身份清单，生成原文页缓存，运行严格评分，查看每条指标的二元兼容值、证据态、正式判决态、证据引文和人工复核标志，再导出工作簿或审查页面。

其实际用途不只在于自动填表，还包括：

- 从大批论文中定位与载磁矿物、构造控制和年轻叠加相关的重点片段；
- 自动发现原文与冻结专家命题之间的支持、冲突和证据缺口；
- 把支持与反证同时呈现给专家，降低人工全文检索成本；
- 对每次规则更新和评分运行进行版本审计；
- 将正式 0/1 样本与 `ABSTAIN`、`BOTH/NEITHER` 待复核样本分流。

知识更新应作为新的离线阶段执行。新增术语、规则、规范命题或阈值后生成新的版本，不能静默覆盖旧版本；生产评分必须同时指定固定知识库和规范判据哈希。

## 17. 局限与待验证事项

1. 原文缺失或 OCR 质量差会直接限制可达到的全量准确率，系统应诚实输出 `UNKNOWN`；
2. 按规范化目标统计，720/3,173 行存在同一 `REFNO+ROCKNAME` 多 `RESULTNO`，需要从原文恢复磁化分量、pole 或方向标识后才能逐记录区分；
3. R5 正式正锚在现有原文中极稀疏，辅助 structural SUPPORT 不能替代刚性克拉通或最后变形后侵入体证据；
4. R7 尚无合格年轻参考极目录，无法系统执行坐标、A95、年龄、时期、可靠度和克拉通范围的联合比较；
5. 当前时序关系是规则级局部三元组，尚未实现事件区间图的闭包、一致性和循环检查；
6. 当前规则库仍需跨文献年代和不同写作风格扩展，但新增词法不能替代缺失的结构化领域数据；
7. R5/R7 负例通常较少，单看 accuracy 容易被多数类掩盖，必须检查正式 coverage、known rows 和 `F1(0)`；
8. 当前规则阈值是可调实施参数，不应在独立测试标签上反复调优；
9. `UNKNOWN/ABSTAIN` 的二元兼容占位值会影响总体 accuracy，评测报告必须同时展示证据态和正式判决态；
10. 术语图来源于历史字段表达，因此应持续检查术语偏差，但在线评分不能回读该字段；
11. 专利申请前仍需检索科学事实核查、知识图谱冲突检测、可撤销推理、证据聚合、时空约束和受控机器学习流水线等现有技术。
12. `exact300` 已经历多轮候选开发并达到 90.00%，后续不得继续依据其逐行错误选择模型后仍称其为独立验证；应冻结新论文或新时间段作为不可回看外部集。

其中第 2 项的下一产物应为原文派生的 `source-derived component manifest`：保存论文内分量名称、对应目标、方向/pole、页表位置和证据哈希。它只能由原文语义和版面关系建立，不能根据 `RESULTNO`、当前评测值或工作表行序反推组件。目标 pole 接受数为 0 的现实原因之一，是极坐标和 A95 常位于 PDF 表格；版面/表格保真抽取及目标行绑定尚未实现，不能列入“已实现”能力。

## 19. 专利撰写前的证据清单

### 19.1 下一关键数据产品：合格参考极目录

应优先建设版本化、记录无关的 `qualified_reference_pole_catalog`。它不是 R7 答案表，而是可供任意目标查询的领域事实目录。每条参考极至少包含：

| 字段组 | 最小字段 |
| --- | --- |
| 身份与对象 | `reference_pole_id`、岩体/地层、磁化分量、所属论文 DOI |
| 球面位置 | pole latitude、pole longitude、坐标约定、A95；如可得再保存 `N/R/kappa` 和分布类型 |
| 时间 | 年龄下限/上限、单位、地质时期、年代地层表版本 |
| 可靠度 | 修订判据可靠度 `R`、各子判据、明确的 `R>=3` 可查询状态 |
| 构造地理 | `craton_id`、相连克拉通关系、稳定区域/造山带状态、现代及古地理范围与版本 |
| 来源溯源 | DOI、页号、表号/行号、原文引文、引文和页面哈希、提取方式、人工复核者、目录版本 |

R7 查询产物还应保存目标极、候选参考极、球面角距、A95 重叠结果、年龄差与时期差、可靠度门、克拉通门、排除原因和每一步 provenance。缺少任一正式必需字段时返回 `ABSTAIN`，不能用点距离或普通 “younger pole” 文本补齐。

### 19.2 归档与实验材料

在提交申请或对外宣称性能之前，建议补齐并归档：

1. 冻结知识库、规范判据、原始判据附件、术语图和测试集划分的哈希；
2. 全量严格评分运行清单和边界审计报告；
3. 独立评测脚本、输入哈希和完整指标报告；
4. REFNO 分组留出或外部集的划分依据；
5. 目标绑定、时序门控和矛盾保留聚合的消融结果；
6. 至少若干 R3、R5、R7 成功、失败、`ABSTAIN`、`BOTH` 和 `NEITHER` 样本的匿名化证据链；
7. 与关键词检索、普通规则投票和一般知识冲突检测方案的现有技术对比；
8. 发明人对关键规则设计、技术贡献和版本演进的书面记录。

上述材料应将“技术方案可实施”“边界确实无标签”“具体数据集上的实验效果”和“法律上的新颖性/创造性”分别证明，避免相互替代。
